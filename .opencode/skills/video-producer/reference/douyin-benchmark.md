# 抖音带货片方法论（从参考成品反推）

本文件是 `analyze_reference.py` 拆解结果的沉淀，供写文案时对照。
数据来源：`work/reference/style-spec.json`，样本为一条 40.8s 的内衣带货片。

---

## 1. 节奏

| 指标 | 实测值 |
|---|---|
| 总时长 | 40.8s |
| 镜头数 | 26 |
| 平均镜长 | 1.57s |
| 镜长 P10 / P50 / P90 | 0.67s / 1.37s / 2.68s |
| 切换方式 | 全部硬切，无转场 |
| 音乐 | 129 BPM，有稳定节拍 |

结论：**每 1.5 秒换一次画面**，最长不超过 3 秒。信息密度靠画面切换而非推拉运镜。

## 2. 文案结构

29 句口播，平均 1.4 秒一句，每句 6–12 字，与画面同步切换。

| 阶段 | 时长占比 | 作用 | 原片例句 |
|---|---|---|---|
| 钩子 | 0–10% | 先给结论，制造反差 | 好穿是好穿 / 显瘦也是真显瘦 |
| 反向筛选 | 10–15% | 用"劝退"制造好奇 | 但小胸姐妹我不建议你去拍 |
| 痛点放大 | 15–20% | 描述具体尴尬场景 | 我怕你穿上之后秒变纸片人 / 不想虎背熊腰壮如牛 |
| 产品引入 | 20–25% | 一句话给出解法 | 都去换成这款深v裸感内衣 |
| 效果确认 | 25–30% | 短句强化 | 上身显瘦贼明显 |
| 卖点铺陈 | 30–75% | 材质→设计→功能→结构，每句一个点 | 奶皮质感面料 / 前扣设计 / 一体式固定杯垫 |
| 效果升华 | 75–85% | 从功能回到感受 | 把胸型衬托的圆润饱满又有型 |
| 促单 | 85–100% | 价格锚点 + 行动指令 | 关键他家现在新品冲销量 / 你看它啥价 |

写文案时沿这条骨架走，但**每个卖点必须在素材里看得见**。

## 3. 视觉

| 项 | 实测值 | 复刻方式 |
|---|---|---|
| 画幅 | 3:4（576×768） | 输出 1080×1440，从 4:3 素材裁切 |
| 字幕位置 | 画面高度 78.4% 起 | `marginV` 按画高比例推导 |
| 字幕字形 | 白字 + 黑描边，无底色 | ASS 主色 `&H00FFFFFF`，描边 3 |
| 字幕字号 | 约占画高 3% | 字号 = 画高 × 0.030 |
| 字幕对齐 | 居中，单行 | `Alignment=2` |
| 角标 | 右上角小字 | 深色描边，占画高 1.5% |
| 色调 | 暖棕、饱和度略高、高光柔和 | eq + colorbalance 微调 |

## 4. 声音

| 项 | 实测值 |
|---|---|
| 整体响度 | -24.3 LUFS（源片未做标准化，成片建议 -14） |
| 真峰值 | -2.81 dBTP |
| 人声占比 | 99.9%（全程有口播） |
| 配乐 | 有，与口播同时存在 |
| 配音来源 | AI（片中有"本视频由AI配音 非真人发声"角标） |

## 5. 硬性规则

1. 用 AI 配音必须在片中标注，否则平台判违规。
2. 字幕单行不超过 14 字，超了要断句。
3. 每句文案对应一个镜头，不要一句话跨多个画面。
4. 前 3 秒必须出现钩子，否则完播率崩。
5. 素材没有的画面不要写；宁可变叙事角度，也不要编效果。
