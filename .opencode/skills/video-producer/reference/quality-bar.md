# 质量基线（交付判定标准）

这份文件是 `qc.py` 判定的依据，也是 AI 判断"能不能交付"的唯一标准。
数值来自实际跑通的成片（47.5s / 1080×1440 / 26 句），不是拍脑袋定的。

改动任一阈值都属于改交付契约，需在 AGENTS.md 里记录。

---

## 1. 硬性红线（任何一条不达标 → 不允许交付）

| 指标 | 阈值 | 说明 |
|---|---|---|
| 整体响度 | -16 ~ -12 LUFS | 抖音推荐 -14 |
| 真峰值 | ≤ -0.5 dBTP | 防止削波 |
| 黑帧 | 0 处 | 渲染事故 |
| 音画时长偏差 | ≤ 0.4s | 超过说明转场链或帧对齐有问题 |
| 字幕条数 vs 配音条数 | 必须相等 | 不等说明 script 与 tts 不同步 |
| 单行字幕字数 | ≤ 14 字 | 超过会折行压画面 |

## 2. 结构指标（不达标 → 需要解释，或以 warn 交付）

| 指标 | 目标区间 | 实测基线 |
|---|---|---|
| 成片时长 | 40 – 55s | 47.5s |
| 镜头数 | 22 – 32 | 27 |
| 平均镜长 | 1.3 – 1.9s | 1.76s |
| 镜长 P10 | ≥ 0.5s | 0.57s |
| 镜长 P90 | ≤ 3.0s | 2.6s |
| 相邻镜头同素材 | 0 | 0 |
| 同一素材复用次数 | ≤ 2 | 2 |
| 溶解转场占比 | 40% – 75% | 73% |
| 画面相似度 P90 | ≤ 0.48 | 0.465 |

## 3. 语义对齐（本生产线的核心指标）

| 指标 | 阈值 | 说明 |
|---|---|---|
| 有画面诉求的句子命中率 | ≥ 60% | `semanticScore > 0` 的比例 |
| 颜色/花纹错配 | 0 | 说黑色配棕色属于硬错，一票否决 |
| 同句多镜主体一致 | 100% | 拆成两镜时必须同一主体 |

"有画面诉求的句子"指文案里出现了具体名词（前扣/肩带/底纹/颜色/包装/多款等），
"挖到宝了""穿一整天都很自在"这类泛化表述不计入分母。

## 4. 已知不达标时的处理顺序

1. 先看是不是**文案超出素材**（说了素材里没有的画面）→ 改文案，不动剪辑
2. 再看是不是**语义规则漏了词** → 补 `SEMANTIC_RULES` / `ACTION_RULES`
3. 最后才调参数（`DIVERSITY_WEIGHT`、`DISSOLVE_SEC`、`MIN_SHOT_SEC`）

顺序不能反。先调参数往往是在掩盖文案与素材的错配。
