# 视频剪辑助手

把「一批原始素材」+「一条参考成品」变成「一条同风格的原创成片」。
基于 opencode 的项目级方案，全程本机运行，素材不出本机。

> 不懂技术也能用：你只需要把视频放进指定文件夹，然后跟 AI 说人话。

---

## 它能做什么

| 能力 | 说明 |
|---|---|
| 拆解参考片 | 自动识别镜头切换、字幕位置、逐句文案、节奏与响度 |
| 素材体检 | 把原始素材切成可用片段，标注「主体｜动作｜细节」 |
| 按口播选画面 | 文案说"前扣"，画面就找有前扣证据的镜头 |
| 本地配音 | CosyVoice3 端侧合成，支持固定音色或克隆你的声音 |
| 自然转场 | 手在收商品时用溶解接走，静止帧用硬切 |
| 自动质检 | 响度、黑帧、音画同步、画面重复度、语义命中率 |
| 版本库 | 每次出片自动编号存档，永不覆盖，可随时回到任意一版 |

---

## 快速开始

```bash
# 1. 装环境（首次约 30–50 分钟，主要在下模型）
bash .opencode/skills/video-producer/scripts/bootstrap.sh

# 2. 自检
.tools/py/pipeline/bin/python .opencode/skills/video-producer/scripts/doctor.py
```

然后把素材放进 `素材/`，参考片命名为 `参考视频/reference.mp4`，
打开 `opencode`，跟助手说：

```
帮我按参考视频的风格剪一条，卖点是显瘦、前扣方便、三角杯不空杯
```

## 目录

```
素材/          你的原始视频（只读，AI 不会动）
参考视频/      想模仿的那条抖音视频（reference.mp4）
成片/          每次生成的成片，按 v01、v02 编号，永不覆盖
过程文件/      AI 的中间产物，不用打开
```

## 运行要求

| 项 | 要求 |
|---|---|
| 系统 | macOS（Apple 芯片） |
| 内存 | 16GB 以上，建议 24GB |
| 磁盘 | 20GB 以上空闲（依赖约 11GB） |

## 版本机制

她一定会反复：觉得第一版好，过一会儿觉得第三版好，最后又回到第一版。

所以每次出片都会生成只读快照：

```
成片/
├── v01/  成片.mp4  封面.jpg  说明.md  script.json  edit-plan.json
├── v02/
└── 版本清单.md
```

已保存的版本**永不修改、永不删除**。想回到某一版，直接说「回到第 1 版」。
